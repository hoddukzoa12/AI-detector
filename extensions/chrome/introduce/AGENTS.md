# 기존 소비자 제품의 소개 콘텐츠

## 범위

정적 랜딩 페이지, 블로그 원문·HTML, 블로그 빌드 스크립트를 맡는다. 공모전용 점검 화면이나 실행 앱은 이 폴더의 범위가 아니며 콘텐츠 변경이 탐지 기능을 구현하지 않는다.

## 유지 조건

현재 페이지는 소비자용 마스킹·악플 피해자 지원 제품을 설명한다. 공모전 전환만으로 공개 페이지의 제품 문구를 자동 게시·교체하지 않는다. 코드가 원문 전체를 저장하지 않는 캡처를 전체 DOM 보존으로 광고하거나 해시를 법적 효력 보장으로 표현하지 않는다. 실재하지 않는 출처·통계·판례를 추가하지 않는다. 기존 도움 창구와 면책 문구를 콘텐츠 작업과 무관하게 지우지 않는다.

## 구현과 확인

정적 HTML은 실행 앱의 빌드와 분리되어 있다. 같은 콘텐츠의 Markdown·HTML을 고칠 경우 메시지를 맞추고 상대 링크·페이지 표시를 확인한다. 블로그 생성은 `build-blog.mjs`가 담당하며 탐지 코드·WebView·서비스 설정을 이 폴더에 넣지 않는다. 공개 배포는 별도 사용자 지시가 필요하다.
