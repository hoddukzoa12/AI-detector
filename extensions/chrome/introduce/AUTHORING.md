# introduce 콘텐츠 — 유지·확장 가이드

인포커터의 소개·마케팅·블로그 콘텐츠를 어떻게 구성했고, 어떻게 새로 추가/수정하는지 정리한 문서입니다.

## 폴더 구조

```
vibecode-chrome-extension-infocutter/
├── .claude/skills/                  # infocutter 전용 콘텐츠 스킬 (확장 스코프)
│   ├── infocutter-voice/SKILL.md         보이스·포지셔닝 (호출형)
│   └── infocutter-blog-post/SKILL.md      블로그 글 템플릿·인용 규칙 (호출형)
└── introduce/
    ├── index.html                   # 반응형 랜딩 페이지 (자체 완결, 외부 의존성 0)
    ├── README.md                    # 랜딩 본문(마크다운) — index.html 과 메시지를 맞춤
    ├── SKILL.md                     # 보이스 가이드 (문서형, 콘텐츠 옆 참조용)
    └── blog/
        ├── README.md                # 블로그 인덱스 (마음·회복 / 증거·법 분류)
        ├── SKILL.md                 # 블로그 글 작성 규칙 (문서형)
        └── NN-*.md                  # 블로그 글 15편 (01~15)
```

## 스킬 위치와 호출 (중요)

두 스킬은 **이 확장 폴더 안**(`vibecode-chrome-extension-infocutter/.claude/skills/`)에 둡니다 — infocutter 전용이라 mono 루트나 전역(`~/.claude/skills`)에 두지 않습니다.

- 자동으로 `/infocutter-voice`, `/infocutter-blog-post` 로 호출하려면 **이 확장 폴더를 작업 루트로 열어** Claude를 실행하세요.
- mono 루트에서 작업할 때는 목록에 자동으로 안 뜰 수 있습니다. 그때는 `introduce/SKILL.md`·`introduce/blog/SKILL.md` 문서를 직접 참조하면 됩니다(내용 동일).

## 새 블로그 글 추가하기

1. **주제 정하기** — 기존 15편과 겹치지 않는 각으로. (심리/정신건강/회복/디톡스/명예훼손/모욕죄/고소절차/증거 무결성/증거보전·공증/플랫폼 신고/조력자/청소년/공연성/딥페이크/2차 가해 등은 이미 다룸)
2. **`/infocutter-blog-post` 호출** (또는 `blog/SKILL.md` 템플릿 수동 적용).
3. **실제 출처로만 작성** — WebSearch/WebFetch 로 확인한 출처만 URL과 함께 인용. 허위 인용·가짜 통계·없는 판례번호 금지. 불확실하면 `> 요지:` 의역으로.
4. **frontmatter + 구조** — `title/date/tags/summary` + 공감 도입 → 본문 → "그래서 무엇을 할 수 있을까"(여기서 제품 1~2회 자연 연결) → 면책 + 자살예방상담 **109** + `## 참고 자료`.
5. **파일명** `NN-kebab-영문.md` (번호 연속), **`blog/README.md` 인덱스에 한 줄 추가**.
6. **분량** 700~1,200자(공백 제외) 내외.

## 톤·금지선 (요약)

보이스 정본은 [SKILL.md](SKILL.md). 핵심:

- **위로 → 안심 → 설득** 순서. "당신 잘못이 아니다 → 이제 안 봐도 된다 → 우리가 대신 한다."
- **공포 마케팅 금지**: 악플 원문·욕설 예시 노출 금지. 통계는 1~2개, 출처와 함께.
- **과대광고 금지**: "고소하면 이긴다" 류 금지. 본 도구는 소명 참고자료를 도울 뿐 공증·포렌식·법률상담·심리치료를 대신하지 않음을 명시.
- **자살·죽음 소재는 책임 있게** + 항상 **109** 안내.
- **피해자 비난 금지**.

## 랜딩(index.html) 수정 시

- `index.html` 은 자체 완결형(인라인 CSS, 외부 의존성 없음)입니다. 메시지를 바꾸면 `README.md`(마크다운 본문)와 톤·문구를 맞춰 주세요.
- 도움 창구(109/ECRM 등)와 면책 문구는 항상 유지합니다.

## 제품-가치 연결 (모든 글이 닿아야 할 지점)

| 피해자의 고통 | 인포커터가 끊는 지점 |
|---|---|
| 불안해서 자꾸 검색·재열람 | 이름 등록 → 자동 가림(마스킹) |
| 통제 불능감 | "보는 건 막고 증거는 자동 보존" |
| 삭제 공포로 인한 캡처 강박 | 한 번 클릭 → 해시 포함 PDF + 원본 보존 |
| 고립감 | "혼자 견디지 마세요" + 전문 도움 연결 |
