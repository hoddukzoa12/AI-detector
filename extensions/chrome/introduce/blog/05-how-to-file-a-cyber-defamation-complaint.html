사이버 명예훼손 고소, 어디서 어떻게 시작하면 될까요

2026-05-30 · 법률가이드

악플이나 허위 게시글을 발견했을 때, 무엇부터 해야 할지 막막하죠. 화가 나고 억울한데 어디에 신고해야 하는지, 어떤 자료를 챙겨야 하는지 모르면 시간만 흘러가요. 확인된 절차만 단계별로 정리해 드릴게요.

1단계 — 증거를 먼저, 그리고 빠르게

온라인 게시글은 가해자가 언제든 삭제할 수 있어요. 삭제되면 수사기관이 자료를 확보하기 어려워져요. 실무에서도 "하루 이틀 지체하는 사이에 게시글이 삭제되어 증거 확보에 어려움을 겪는 경우"가 적지 않다고 해요.

캡처할 때 반드시 포함해야 할 것들이에요.

  • URL 주소 — 게시물의 직접 링크
  • 작성 일시 — 날짜·시각이 화면에 보이도록
  • 작성자 닉네임 또는 아이디
  • 플랫폼명 — 어떤 서비스인지

게시물 전체가 보이도록 캡처하되, 작성일·닉네임·URL을 포함하는 게 필수예요. 화면 녹화까지 해두면 증거력이 높아져요.

캡처 파일은 원본 그대로 보관하고, 플랫폼 고객센터에 "게시물 보존 요청"을 신청해 두면 추가 안전망이 돼요.

2단계 — 법적 근거 확인

사이버 명예훼손은 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」 제70조로 처벌돼요. 구체적 처벌 수위나 본인 사안의 성립 여부는 변호사 상담을 권해요.

3단계 — ECRM으로 온라인 신고 접수

경찰청이 운영하는 사이버범죄 신고시스템(ECRM) 을 이용하면 온라인으로 신고를 접수할 수 있어요. 접수 절차는 "온라인 접수 → 경찰서 방문 → 조사 → 종결" 4단계예요.

1. ecrm.police.go.kr 접속 2. 휴대전화·아이핀 등으로 본인 인증 3. 범죄 유형 선택 후 진술서 작성, 캡처 파일 첨부 4. 접수 완료 후 임시 접수번호 또는 안내 문자 확인 → 가까운 경찰서 방문 필수

ECRM은 경찰서 방문 전에 민원서류 작성을 지원하는 시스템이라, 형사사건 진행을 위해서는 직접 경찰서를 방문해야 해요. 방문할 때는 신분증, 캡처 출력본, 관련 대화 내역 등을 함께 지참하면 접수가 더 원활해요.

오늘 할 수 있는 것

고소 절차의 첫 관문은 증거 정리예요. 캡처·URL·날짜를 빠짐없이 모으는 게 가장 중요해요. 두렵고 힘든 상황에서도 이 한 단계를 챙겨두면, 나중에 선택지가 훨씬 넓어져요. 혼자 다 감당하지 않아도 돼요. 변호사 상담을 통해 자신의 상황에 맞는 방향을 찾아보세요.

이 글은 일반 정보예요. 구체적인 일은 변호사와 상의하세요. 많이 힘들 땐 자살예방상담 109(24시간)가 있어요.
