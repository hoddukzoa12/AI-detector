# Infocutter Generated Image Assets

This directory is for raster image assets only. The current set should not include the product logo.

### Full description draft

```text
인포커터는 보고 싶지 않은 이름과 별칭을 웹페이지에서 자동으로 가리고, 필요한 순간 증거 PDF로 정리할 수 있게 돕는 Chrome 확장 프로그램입니다.

악성 댓글, 추천 피드, 검색 결과, 영상 페이지처럼 반복해서 마주치기 쉬운 화면에서 사용자가 등록한 이름을 감지하고 관련 텍스트 블록을 마스킹합니다. 원문을 오래 바라보지 않아도 되도록 화면을 먼저 정리하고, 사용자가 선택하면 URL, 캡처 시간, SHA-256 해시 정보를 포함한 증거 자료를 보존합니다.

주요 기능
- 이름과 별칭 기반 자동 마스킹
- 사이트별 규칙과 예외 관리
- YouTube, Shorts 등 페이지 유형별 패널 배치
- URL, 시간, 해시 메타데이터가 포함된 증거 PDF 생성
- 분석 결과를 나중에 정리하기 쉬운 구조화 데이터로 저장

인포커터는 법률 상담, 공증, 디지털 포렌식, 심리 치료를 대신하지 않습니다. 다만 상처가 되는 화면을 반복해서 보지 않아도 되게 하고, 필요한 자료를 차분하게 모으는 과정을 돕습니다.
```

## Generated PNG Set

Files are saved under `generated/`:

- `thumbnail-hero.png`: no-logo hero thumbnail
- `promo-small.png`: no-logo small promotional image
- `promo-marquee.png`: no-logo wide promotional image
- `screenshot-auto-mask.png`: automatic masking concept
- `screenshot-evidence-pdf.png`: evidence capture concept
- `screenshot-settings.png`: rules/settings concept
- `screenshot-shorts.png`: YouTube Shorts side-panel concept
- `screenshot-database.png`: structured record/database concept
