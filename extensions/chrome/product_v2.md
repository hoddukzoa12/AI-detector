# 인포커터 판매용 제품 설명서 v2

## 한 줄 포지션

사이트별로 보기 싫은 영역과 텍스트 블록을 직접 잘라내는 개인용 웹 화면 정리 Chrome 확장.

## 누구에게 파는가

- 광고, 추천 피드, 사이드바, 팝업 때문에 웹페이지 집중도가 떨어지는 사용자
- 특정 사이트의 반복 노이즈를 매번 닫거나 스크롤로 피하는 지식 노동자
- 가족, 학생, 팀원에게 더 깨끗한 읽기 환경을 제공하려는 운영자
- 네트워크 필터와 DOM 숨김을 함께 관리하고 싶은 파워 유저

## 사용 목적

인포커터는 웹페이지에서 불필요한 정보 영역을 사이트별 규칙으로 숨기는 데 쓴다. 광고 차단만이 목적이 아니라, 사용자가 직접 "이 사이트에서는 이 박스, 이 피드, 이 문구를 안 보겠다"를 저장하는 화면 정리 도구다.

브라우저 확장 아이콘을 눌러 페이지에서 제거할 요소를 선택하고, 선택된 CSS selector를 사이트 규칙으로 저장한다. 이후 같은 사이트에 방문하면 저장된 selector가 자동 적용되어 해당 영역이 보이지 않는다. 텍스트 블록 규칙과 네트워크 필터 가져오기도 함께 있어, DOM 요소와 요청 단위 노이즈를 함께 줄일 수 있다.

## 판매 메시지

### 핵심 문구

"매번 닫던 광고와 방해 요소를 한 번만 찍어두면, 그 사이트는 계속 조용해집니다."

### 문제 제기

웹은 점점 읽을 내용보다 방해 요소가 많아진다. 광고, 추천 피드, 실시간 랭킹, 로그인 유도, 사이드 위젯은 사이트마다 위치와 구조가 달라 범용 차단 규칙만으로는 깔끔하게 정리되지 않는다.

### 해결 방식

인포커터는 사용자가 직접 페이지 위에서 숨길 영역을 고르게 한다. 선택한 규칙은 사이트별로 저장되고, 이후 방문할 때 자동 적용된다. 필요한 사이트에만 필요한 만큼 숨기기 때문에, 전체 웹을 과하게 망가뜨리지 않고 개인화된 정리 상태를 유지할 수 있다.

## 주요 기능

- 페이지 위 요소 선택으로 숨김 selector 생성
- 사이트별 숨김 규칙 저장 및 자동 적용
- 선택 후보 preview로 잘못 숨기기 전 확인
- 저장된 규칙 관리, 활성/비활성 전환, 삭제
- 텍스트 조건 기반 블록 숨김
- 필터 템플릿 가져오기와 네트워크 규칙 관리
- Chrome MV3 `declarativeNetRequest` 기반 요청 차단 지원
- 네이버 홈 광고 템플릿 같은 사전 규칙 파일 기반 확장 가능

## 사용 흐름

1. `./infocutter dev`로 빌드한 뒤 Chrome 확장 관리 화면에서 `dist` 폴더를 로드한다.
2. 정리하고 싶은 웹사이트를 연다.
3. 확장 팝업에서 요소 선택을 시작한다.
4. 페이지 위에서 숨기고 싶은 광고, 추천 영역, 사이드바, 피드 블록을 클릭한다.
5. preview로 숨김 범위가 맞는지 확인한다.
6. 사이트 규칙으로 저장한다.
7. 같은 사이트를 다시 열어 규칙이 자동 적용되는지 확인한다.
8. 옵션 화면에서 규칙을 켜고 끄거나, 텍스트 블록/네트워크 필터를 추가로 관리한다.

## 대표 사용 사례

### 포털 홈 화면 다이어트

뉴스 피드, 쇼핑 광고, 우측 광고 박스, 실시간 추천 영역을 사이트별 selector로 숨긴다. 자주 들어가는 포털의 첫 화면을 검색과 핵심 콘텐츠 중심으로 바꿀 수 있다.

### 문서/블로그 읽기 환경 정리

본문 옆 추천 글, 구독 유도, 하단 배너, 떠다니는 공유 버튼을 숨겨 긴 문서를 읽기 쉬운 상태로 만든다.

### 업무용 SaaS 화면 집중 모드

매일 보는 관리 도구에서 쓰지 않는 위젯, 안내 배너, 프로모션 영역을 숨긴다. 팀원이 같은 템플릿을 가져오면 비슷한 업무 환경을 빠르게 맞출 수 있다.

## 썸네일 제작 방향

### 목표

썸네일만 보고 "웹페이지의 방해 요소를 직접 잘라내어 깨끗하게 만든다"는 목적이 보여야 한다.

### 금지

- SVG 스타일의 단순 가위 아이콘만 크게 보여주는 이미지
- 광고 차단을 연상시키는 일반적인 방패 아이콘 중심 이미지
- 실제 웹페이지 정리 전후가 보이지 않는 추상 이미지

### 실제 그리는 방식

래스터 일러스트 또는 디지털 페인팅 스타일로 제작한다. 한 화면 안에 왼쪽은 광고와 추천 피드가 복잡한 웹페이지, 오른쪽은 인포커터가 적용되어 깨끗해진 같은 페이지를 나란히 그린다. 중앙에는 사용자가 커서로 광고 박스를 선택하고, 선택된 영역이 붉은 점선 또는 반투명 마스크로 사라지는 장면을 넣는다.

### 권장 구성

- 16:9 썸네일
- 배경: 실제 포털/뉴스/블로그처럼 보이는 페이지 구조
- 전경: 선택 오버레이와 제거 preview
- 대비: Before 쪽은 광고 박스와 추천 피드가 많고, After 쪽은 본문과 검색/핵심 콘텐츠만 남음
- 보조 요소: 작은 팝업에 "사이트 규칙 저장", "텍스트 블록", "네트워크 필터" 항목이 보임
- 카피: "한 번 찍으면 계속 조용한 웹"

## 구매자가 기대할 결과

인포커터를 쓰면 매번 닫거나 무시하던 웹 노이즈를 사이트별 규칙으로 고정 제거할 수 있다. 목적은 모든 광고를 무조건 막는 것이 아니라, 사용자가 실제로 보는 화면을 자기 업무와 읽기 습관에 맞게 정리하는 것이다.
