# 기존 텍스트 차단 모델

## 범위

`src/index.ts`의 텍스트 블록 설정, 오브젝트 태그, 활성 상태와 저장소 정규화를 맡는다. 저장소 접근·메시지 송수신·UI·자동 페이지 순회는 이 패키지의 범위가 아니다. 현재 소비자는 Chrome 확장이고 Flutter는 별도 Dart 구현을 사용한다.

## 재사용 조건

이 모델은 사용자가 원치 않는 텍스트를 차단하는 기존 규칙이다. 광고 문맥·자모 복원·은닉 기법 판정을 제공한다고 취급하지 않는다. 잘못된 입력 처리와 기존 태그 정규화를 재사용 변경에서 보존한다.

다른 패키지를 import하거나 `chrome.*`를 호출하지 않는다. 컴파일 결과는 확장 빌드가 ES 모듈로 사용하고 필요한 export는 IIFE 전역으로 노출한다. 새 export가 content script에 필요하면 해당 빌드 반환 목록과 선언을 함께 확인한다.

## 검증

검사는 확장 루트 `npm run pipe:test`로 실행한다. 태그 정규화·활성 조건·누락 필드·잘못된 입력을 확인한다. 타입 검사 통과와 실제 DOM 동작은 별개이며, 공모전 탐지 성능은 이 패키지의 기존 테스트 통과만으로 입증되지 않는다.
