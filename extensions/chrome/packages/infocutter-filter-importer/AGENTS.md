# 기존 필터 해석

## 범위

`src/index.ts`의 AdBlock·uBlock 형식 줄 해석, 선택자·예외·텍스트 조건·네트워크 규칙 변환을 맡는다. 저장소 접근·메시지 송수신·UI·자동 페이지 순회는 이 패키지의 범위가 아니다. 현재 소비자는 Chrome 확장이고 Flutter는 별도 Dart 구현을 사용한다.

## 재사용 조건

지원하지 않는 수정자는 이유와 함께 제외하고 임의로 비슷한 차단 규칙을 만들지 않는다. 광고 차단 목록이 맞았다는 사실을 불법광고의 은닉 유형 정답으로 제출하지 않는다.

다른 패키지를 import하거나 `chrome.*`를 호출하지 않는다. 컴파일 결과는 options와 service worker에서 ES 모듈로 사용한다. 현재 content script용 IIFE 전역은 만들지 않는다.

## 검증

검사는 확장 루트 `npm run pipe:test`로 실행한다. cosmetic·예외·텍스트 조건·스크립트 필터 제외·허용 규칙·지원하지 않는 수정자를 확인한다. 타입 검사 통과와 실제 DOM 동작은 별개이며, 공모전 탐지 성능은 이 패키지의 기존 테스트 통과만으로 입증되지 않는다.
