# 기존 이름 감시 모델

## 범위

`src/index.ts`의 이름·별칭 저장소 정규화, 검색어 목록, 부분 문자열 매칭을 맡는다. 저장소 접근·메시지 송수신·UI·자동 페이지 순회는 이 패키지의 범위가 아니다. 현재 소비자는 Chrome 확장이고 Flutter는 별도 Dart 구현을 사용한다.

## 재사용 조건

기존 대소문자·공백 처리와 두 글자 미만 검색어 제외를 불법광고 판정 기준으로 그대로 가져오지 않는다. 이름 감시 결과를 필수 네 은닉 유형의 검출로 바꾸지 않는다.

다른 패키지를 import하거나 `chrome.*`를 호출하지 않는다. 컴파일 결과는 확장 빌드가 ES 모듈로 사용하고 필요한 export는 IIFE 전역으로 노출한다. 새 export가 content script에 필요하면 해당 빌드 반환 목록과 선언을 함께 확인한다.

## 검증

검사는 확장 루트 `npm run pipe:test`로 실행한다. 꺼진 대상·별칭 중복·빈 값·두 글자 미만·공백과 대소문자를 확인한다. 타입 검사 통과와 실제 DOM 동작은 별개이며, 공모전 탐지 성능은 이 패키지의 기존 테스트 통과만으로 입증되지 않는다.
