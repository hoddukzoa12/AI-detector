# 선택자와 규칙 모델

## 범위

`src/index.ts`의 version 1~4 정규화, URL matcher, 카드·프로필 모델, 선택자 후보 생성 보조, 메시지 타입을 맡는다. 저장소 접근·메시지 송수신·UI·자동 페이지 순회는 이 패키지의 범위가 아니다. 현재 소비자는 Chrome 확장이고 Flutter는 별도 Dart 구현을 사용한다.

## 재사용 조건

기존 저장소와 메시지 값을 임의로 바꾸지 않는다. 알 수 없는 버전의 빈 저장소 처리는 현재 동작이며 이를 새 결과 파일의 오류 처리로 승계하지 않는다. 선택자의 유일성은 대상 문서에서 다시 확인한다.

다른 패키지를 import하거나 `chrome.*`를 호출하지 않는다. 컴파일 결과는 확장 빌드가 ES 모듈로 사용하고 필요한 export는 IIFE 전역으로 노출한다. 새 export가 content script에 필요하면 해당 빌드 반환 목록과 선언을 함께 확인한다. DOM 함수는 대상 문서·요소를 입력으로 받고 현재 창의 상태만을 정답 문맥으로 가정하지 않는다.

## 검증

검사는 확장 루트 `npm run pipe:test`로 실행한다. 이전 버전·문자열 규칙·카드 누락, scheme·port·서브도메인, 선택자 유일성과 nth-of-type 반례를 확인한다. 타입 검사 통과와 실제 DOM 동작은 별개이며, 공모전 탐지 성능은 이 패키지의 기존 테스트 통과만으로 입증되지 않는다.
