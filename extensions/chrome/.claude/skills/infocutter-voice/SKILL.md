# 인포커터 보이스 가이드

정본은 레포의 `vibecode-chrome-extension-infocutter/introduce/SKILL.md` 이며, 랜딩 본문 예시는 `introduce/README.md`. 이 스킬은 그 핵심을 요약한다.

## 한 줄 포지셔닝
> "보이는 건 우리가 가리고, 증거는 우리가 모읍니다. 당신은 그만 봐도 됩니다."

## 보이스 3원칙 (순서 = 설득 구조)
1. **공감** — "당신 잘못이 아니다. 자꾸 보게 되는 건 원래 그렇게 설계된 고통이다." 고통을 정상화한다.
2. **안심** — "이제 안 봐도 된다. 가리는 건 자동, 증거는 알아서 남는다." 통제감을 돌려준다.
3. **설득** — 부드러운 CTA. 강요·죄책감 금지. "1분이면 시작할 수 있어요."

## 금지선
- **공포 마케팅 금지**: 악플 원문·욕설을 예시로 노출하지 않는다. 통계는 1~2개만, 반드시 출처와 함께.
- **과대광고 금지**: "고소하면 이긴다" 류 금지. 본 도구는 **소명 참고자료**를 도울 뿐 공증·포렌식·법률상담·심리치료를 대신하지 않는다고 정직히.
- **자살·죽음 소재는 책임 있게**: 사실만 간결히, 자극 금지, 반드시 **자살예방상담 109(24시간)** 등 도움 창구 동반.
- **피해자 비난 금지**.

## 제품-가치 연결
| 피해자의 고통 | 인포커터가 끊는 지점 |
|---|---|
| 불안해서 자꾸 검색·재열람(자기 가해) | 이름 등록 → 자동 가림(마스킹) |
| 통제 불능감 | "보는 건 막고 증거는 자동 보존" |
| 삭제 공포로 인한 캡처 강박 | 한 번 클릭 → 해시 포함 PDF + 원본 보존 |
| 고립감 | "혼자 견디지 마세요" + 전문 도움 연결 |

## 타깃별 미세 조정
- **연예인/공인**: 규모의 무력감("수천 개를 다 볼 수 없잖아요. 핵심만 가리고 증거는 자동으로.")
- **일반인**: 개인적 상처·증거 강박("캡처하느라 더 상처받지 마세요.")

블로그 글을 쓸 때는 [[infocutter-blog-post]] 스킬을 함께 사용한다.
