# 점검 실행 제어

crawler/detection/ocr/classification/output을 연결하고 동시성·범위/시간 상한·취소·terminal 저장을 맡는다. HTTP 인증·화면 렌더링·플랫폼 패키징은 소유하지 않는다.

키와 CLEF 전송 동의 없으면 실행 생성 전에 거부한다. OCR 미선택은 원본 확보·OCR 요청0이며 CLEF는 모든 은닉 후보와 readable 이미지 글자를 분류한다. 모델 오류를 local 확정으로 대체하지 않는다. 실제 시도·재시도는 공통 예산에 포함하고 캐시 추출은 요청0이다. 수락한 양성과 조각 계획은 복제 보존하고 중단 뒤 확정 결과를 늘리지 않는다. 종료까지 unfinished를 검토로 정리한다.

실제/모의 수집·확정과 미완료 혼합·후보/요청 상한·진행중 양성·late 응답·단일 실행·저장 실패·close 멱등과 env 우선순위를 검사한다.
