# Captured observations and OCR owners

`detectPage(page: CollectedPage): DetectionCandidateV2[]` observes captured direct text without browser access or mutation. Every owner with HOMOGLYPH, JAMO, TRANSPARENT or OFFSCREEN observations remains a CLEF candidate. No local advertising decision, advertising rule IDs, topic exclusion or parent-context classification is produced. `observationIds` retains character/style diagnostics, including `STYLE_AMBIGUOUS_CONCEALMENT` for uncertain styles. These diagnostics establish observations, not advertisement intent.

Each candidate retains exact raw evidence, separate normalization, the nearest owning anchor links collected by T2, frame URL/path and snapshot reference. Locations already contain their full frame path and are copied exactly. Candidate IDs hash URL (including query values), frame path, owner location and sourceType. Repeated captures deduplicate only this identity; independently owned parent, child and sibling text stays distinct. Aggregate-only parents have no direct-text record.

`detectImageCandidates(images: readonly OcrImageOccurrence[], owners: readonly CollectedImageOccurrence[]): DetectionCandidateV2[]` groups persisted OCR records by captured owner. The second argument is T2's metadata from `onPage`; it supplies nearest-anchor links omitted from OCR records. Missing, mismatched or inconsistent owner metadata is rejected. All occurrence IDs remain in sourceIds, ordered by img, css_background, css_before, css_after and then sourceIndex. Only completed readable extraction strings join the rawText with one newline; sourceTextRanges records exact UTF-16 half-open ranges. Separate normalization preserves originals. Images have empty techniques/observationIds; image concealment remains image metadata. Groups without readable text remain empty review candidates, and callers retain ai:null and skip CLEF for them. DOM and image candidate identities are separate.

`analyzeText(rawText): TextAnalysis` and `normalizeText(rawText): string` retain character restoration. Adjacent modern/compatibility Jamo compose without crossing spaces or punctuation. Mixed Latin/Cyrillic/Greek lookalikes and conservative digit substitutions preserve original change spans. The finite lexical restoration table is a character diagnostic; it never confirms, excludes or selects text by advertising intent. Dates, budgets, phones and arbitrary alphanumeric codes remain intact.

Styles use owner foreground/font size, ancestor opacity/display, layered background colors and document coordinates. Fixed elements use viewport coordinates. Ordinary scrolled content does not become OFFSCREEN. Background images prevent unsupported same-color conclusions. Clipping and hidden visibility remain uncertain observations for downstream review.

Tests include independent fixture observations, source ordering/ranges, input immutability, actual Chromium parent/child/iframe regressions, T2 menu reproduction and collected image layers. Injected CLEF responses verify ownership and execution contracts; they do not measure actual model accuracy.
