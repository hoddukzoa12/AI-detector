# 이미지 글자 추출

OpenRouter의 고정 Gemini 모델에 등록된 정적 PNG를 보내 글자만 추출한다. 광고 여부·DOM 위치·은닉 기법·파일 저장·화면은 소유하지 않는다. 광고 분류는 CLEF 담당이다.

사용자가 이미지 OCR 전송을 선택한 실행에서 Node만 키를 사용한다. PNG 데이터·키·인증 헤더·응답 원문을 로그에 넣지 않는다. 다른 모델이나 로컬 OCR로 자동 대체하지 않는다.

엄격한 구조화 응답, 읽기 상태, 원래 추출 문자열, 실제 요청 수·사용량, 고정 입력의 완료 캐시를 보존한다. 읽기 실패를 비광고로 처리하거나 숫자 OCR 신뢰도를 만들지 않는다. 취소 전 미요청과 실제 요청 중 취소를 구분하고 종료 뒤 응답을 수락하지 않는다.

모의 HTTP로 schema·잘림·refusal·오류·재시도·기한·한도·캐시·중단·키 비노출을 검사한다. 실제 한국어 인식 성능은 독립 문자열 정답과 작은 별도 유료 표본으로 확인하며 모의 검사와 구분한다.
