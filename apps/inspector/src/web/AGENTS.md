# 점검 화면

URL·CLEF 전송 동의·선택 이미지 OCR·시작/중단·진행·공식/추가 이미지/검토·상세/근거·JSON 다운로드를 맡는다. Node 키·파일 쓰기·은닉 판정·외부 AI 호출은 소유하지 않는다.

API snapshot와 runId를 기준으로 표시하고 이전 polling 응답을 새 실행에 반영하지 않는다. 수집 자료는 textContent로 출력한다. 0건·partial/failed/cancelled·저장 실패를 구별하며 진행중 다운로드를 성공 저장처럼 표시하지 않는다.

실제 브라우저의 모의 API 상태/XSS/과거 응답 검사와 생산 서버 e2e를 구분한다. 실제 행·상세·cancel·보존 경로·다운로드 바이트를 검사한다.

신규 실행은 V2 API를 소비한다. CLEF와 전송 동의·서버 키 설정은 필수며 이미지 OCR은 기본 꺼짐이다. 한 프레임·요청/바이트/픽셀 한도와 OCR 미선택·무문자·읽기 불가·미처리를 구분한다. 이미지는 해당 실행에 등록된 input asset ID를 인증 조회하여 PNG MIME·nosniff·바이트 서명을 확인한 blob만 표시한다. 원본 URL/SVG/HTML을 표시 자원으로 직접 요청하지 않는다.

취소/새 실행의 조회 세대와 artifact 요청 순서를 함께 확인하고, 종료 후 최종 상세/검토/OCR을 다시 읽는다. 이미지 근거는 원본/PNG 해시·소유 위치/프레임·숨김 관측·추출 원문·읽기 상태·CLEF 조각·캐시로 연결한다.
