# 실행별 파일 보존

공식/추가/상태/검토/상세/OCR·DOM/원본/PNG 근거·manifest·latest 파일을 작성한다. 광고 판정·브라우저·HTTP 인증·화면은 소유하지 않는다.

staging에서 원문·검토·상세 작성 뒤 종료 시각을 확정한다. 실제 바이트를 해시하고 실행별 archive를 먼저 보존한다. 최신 표시를 마지막에 교체하며 새 실패로 이전 archive를 지우지 않는다. 등록되지 않은 경로·루트 밖 symlink를 읽지 않는다.

UTF-8/BOM·빈 결과·상세 일대일·권한/rename/교체 실패·부분 보존·같은 runId·실제 해시·이전 실행과 실패 overlay를 검사한다.
