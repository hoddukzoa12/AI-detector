# 계약과 실행 상태

공식/추가 결과·V2 상태·검토·상세·OCR 계약과 검증, 실행 ID·터미널 고정을 맡는다. 브라우저·파일·외부 HTTP·화면은 소유하지 않는다.

V1 계약은 이전 archive 읽기 호환성으로만 유지한다. 신규 실행은 필수 CLEF·동의·선택 OCR, 소유/발생/UTF-16 범위·해시 관계를 엄격 검증한다. runId별 상태 자료는 복제해 반환하고 종료 뒤 callback·반복 취소로 바뀌지 않는다. 공식 기법은 단일 코드이며 counts·시각·elapsed는 유한한 규격값이다.

잘못된 URL/계약·중복 활성 실행·중단/완료 경쟁·과거 callback·NaN/Infinity·중복 ID를 test/core에서 검사한다.
