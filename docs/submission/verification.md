## 실제 OCR·CLEF 소형 평가

별도 승인된 합성 평가에서 정상 설정 로더의 키를 사용했습니다. 전체 예산 OCR 최대8·CLEF 최대16요청(재시도 포함) 중 실제 OCR 8·CLEF 10회, 모두 HTTP200, 재시도 0회였습니다. 지속되는 호출 기록은 같은 단계 재실행을 거부합니다. 자동 테스트·자체 점검의 모의 요청 수와 실제 요청 수를 합산하지 않습니다.

읽을 수 있는 한글·영문 이미지 6개에서 수작업 정답 총162 Unicode code point와 추출 문자열이 정확히 같았고 문자 차이는0이었습니다. 무문자 이미지는 no_text, 작은 흐림 이미지는 unreadable이었으며 여덟 읽기 상태가 정답과 일치했습니다. OCR confidence는 제공하지 않고 null입니다. 이 쉬운 소형 표본의 문자 일치를 복잡한 실사이트 배너 정확도로 주장하지 않습니다.

CLEF는 추출 글자6건과 독립 텍스트4건 중 9건이 수동 선택과 일치했습니다. MEMBER 제목은 non_ad 정답 대신 uncertain 0.474(non_ad 0.4722)로 응답해 검토에 남았으며 확정 광고 오탐은 아니었습니다. OCR 지연은2,492~6,496ms, CLEF는275~913ms이고 제공된 사용량 비용 합계는0.01596897달러였습니다. 다른 입력의 비용이나 정확도를 보장하지 않습니다. 정규화 결과·상태·확률·사용량·해시와 요청 기록은 `release/verification/ocr-clef/actual-evaluation-T9/`에 있고 키·헤더·이미지 payload·응답 원문은 없습니다.
