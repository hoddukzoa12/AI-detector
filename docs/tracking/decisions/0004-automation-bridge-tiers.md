# 0004. 자동화 브리지는 민감한 동작에만 토큰을 요구한다

- 날짜: 2026-06-13 (이전 저장소 `flutter-app-mono` 커밋 `9f4b35f`)
- 상태: 기존 제품의 결정 이력; 공모전 정책은 별도로 확정

## 배경

디버그 빌드의 자동화 브리지는 MCP 서버와 로컬 도구가 앱을 조작하는 통로다. 루프백 주소에만 bind하지만 같은 기기의 다른 프로그램도 닿을 수 있다. 그중 일부 동작은 로그인된 페이지에서 임의 JS를 실행하거나, 페이지 내용을 빼내거나, 저장된 API 키를 덮어쓴다.

## 결정

동작을 두 등급으로 나눈다. 민감한 동작은 앱을 토큰과 함께 띄운 경우에만 허용하고, 나머지 동작은 로컬 도구가 쓰기 쉽도록 요건을 낮게 둔다. 브리지는 `kDebugMode`에서만 시작한다.

## 검토한 대안

- **모든 동작에 토큰을 요구하는 것**: 로컬 도구로 상태를 읽고 탭을 여는 일상 작업이 번거로워진다는 이유로, 일반 동작의 요건을 낮게 두었다(브리지 코드 주석).

## 결과

- 새 동작을 추가할 때마다 민감한 동작인지 판정해야 한다. 임의 코드 실행, 인증된 페이지 내용 읽기·변경, 비밀 덮어쓰기 중 하나라도 해당하면 민감한 동작 목록에 넣는다.
- 현재 `page.getText`, `page.click`, `page.fill`은 민감 동작 목록에 없어 토큰 없이 현재 페이지 텍스트 읽기·입력·클릭을 요청할 수 있는 코드 경로가 있다. 이 동작은 민감 동작의 설명과 일치하지 않으며 실제 기기 재현은 하지 않았다.
- release 빌드에는 브리지가 없으므로 이 결정은 디버그 빌드에만 영향을 준다.
