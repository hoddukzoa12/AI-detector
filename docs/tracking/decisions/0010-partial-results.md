# 0010. 미완료 실행에서도 확인된 결과를 보존

- 날짜: 2026-10-04
- 상태: 구현·Linux 검증, 실제 Windows·운영 API 평가 조건은 별도

## 배경

페이지 접근 실패나 선택한 AI 분석 실패가 발생해도 다른 페이지에서 이미 확인한 탐지는 유효할 수 있다. 반대로 일부 페이지만 확인한 실행을 광고 없음 또는 전체 완료로 표시하면 관리자가 미점검 범위를 오인한다.

## 결정

접근·AI 오류나 사용자 중단이 있으면 확인된 결과를 저장하고 화면과 별도 실행 기록에 부분 완료·실패·중단 상태와 미완료 범위를 표시한다. 평가용 `result.json`은 공식 `meta`·`findings` 계약을 유지한다. 실행 상태를 검출 항목의 은닉 유형이나 위반 여부에 섞지 않는다.

## 대안

- 오류 한 건으로 전체 실행 실패: 이미 확인한 결과를 잃고 관리자가 활용하기 어렵다. 사용자는 확인된 결과를 저장하는 방향을 선택했다.

## 결과

완료 여부와 검출 건수는 별도 값이다. 빈 탐지 배열을 저장했더라도 미완료 실행을 전체 사이트 광고 없음으로 표시하지 않는다. 별도 상태·검토·확정 상세와 실행별 원문 근거를 보존하며 부분/중단·저장 실패를 실제 검사로 확인했다.
