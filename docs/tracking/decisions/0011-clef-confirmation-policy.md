# 0011. AI 사용 시 CLEF 분류로 확정하고 불확실한 후보는 별도 검토

- 날짜: 2026-10-04
- 상태: 구현·Linux 검증, 실제 Windows·운영 API 평가 조건은 별도; 선택 AI·로컬 판정은 [0012](0012-external-ocr-clef-only.md)로 대체

## 배경

정상 기사·공공 안내에서도 도박·성인물 관련 단어나 숨김 요소가 나타날 수 있다. DOM의 은닉 기법과 광고 문맥은 서로 다른 판정이다. 확정 탐지와 분류가 불확실한 후보를 같은 평가 결과에 넣으면 오탐이 늘어난다.

## 결정

AI 사용 시 DOM에서 은닉 기법을 확인한 후보 중 CLEF가 충분한 확신으로 불법광고로 분류한 항목만 자동 확정한다. 불확실하거나 분류에 실패한 후보는 별도 검토 목록에 남기고 확정 탐지로 제출하지 않는다. 선택한 AI 분석 실패를 숨겨 정상 완료로 표시하거나 로컬 판정으로 조용히 대체하지 않는다. AI를 사용하지 않으면 로컬 규칙으로 판정한다.

## 대안

- 로컬 규칙 우선, CLEF는 참고 정보만 표시: 사용자는 AI를 켠 경우 CLEF 분류로 확정하는 방식을 선택했다.

## 결과

확률 기준은 한국어 광고·기사·안내 사례로 검증하고 조정할 수 있어야 한다. 모델이 작성한 문구를 원문 근거로 대체하거나 모델이 선택자·은닉 기법을 만들어 제출하지 않는다. 검토 목록은 평가용 확정 결과와 구분한다.
