# 0007. 사용자 선택에 따른 외부 AI 분석 허용

- 날짜: 2026-10-04
- 상태: 사용자 확인 완료, 새 앱 구현·Linux 검증; 선택 AI·로컬 판정은 [0012](0012-external-ocr-clef-only.md)로 대체

## 배경

불법광고 문맥 판정에 외부 AI를 사용할 수 있지만 자료 전송과 서비스 설정이 추가된다. 공모전은 AI를 필수로 요구하지 않으며, 상용 AI를 쓴다면 심사자 키를 실행 시 외부 파일에서 읽어야 한다.

## 결정

사용자가 서비스를 설정하고 전송을 선택할 때 후보 텍스트·링크를 외부 AI에 보낼 수 있다. 기본 수집과 로컬 판정에서 외부 AI를 필수 전제로 두지 않는다. API 키는 실행 시 외부 설정 파일에서 읽고 소스에 넣지 않는다. 서비스는 OpenRouter, 모델은 cloudflare/clef, 키는 OPENROUTER_API_KEY다.

## 대안

- 외부 전송을 전부 금지하고 로컬로만 처리: 사용자는 보조 AI 선택지를 허용하는 방향을 승인했다.
- 사용자가 선택하지 않아도 모든 페이지를 자동 전송: 승인된 자료 범위와 전송 조건에 맞지 않아 채택하지 않는다.

## 결과

후보 원문에 공개 개인정보가 포함될 수 있음을 고려해 전송 범위를 안내한다. 쿠키·전체 방문 기록·API 키를 분석 자료에 덧붙이지 않는다. 심사자는 키 교체만으로 동작을 확인할 수 있어야 하며 기존 앱의 보안 저장소나 확장 설정만으로 이 요구를 충족했다고 주장하지 않는다.
