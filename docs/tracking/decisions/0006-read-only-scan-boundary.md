# 0006. 공개 페이지 읽기로 점검 범위를 제한

- 날짜: 2026-10-04
- 상태: 사용자 확인 완료, 새 앱 구현·Linux 검증

## 배경

진입 사이트의 페이지와 포함된 iframe을 조사하는 일과 광고 링크를 따라 외부 사이트까지 조사하는 일은 탐색 규모와 사이트 접근 범위가 다르다. 결과 확인 도구가 실제 게시물을 변경할 필요도 없다.

## 결정

입력 URL과 같은 호스트의 공개 페이지·게시글·댓글과 포함된 iframe을 읽는다. 다른 서브도메인을 별도 페이지로 순회하지 않는다. 포함된 외부 iframe은 읽을 수 있으나 외부 페이지 링크·리다이렉트는 탐색 범위에 추가하지 않는다. 외부 광고 링크 추적, 로그인, 게시물 작성·수정·삭제는 하지 않는다. 사용자 중단·접근 실패 시 확인된 결과와 미완료 범위를 남긴다.

## 대안

- 외부 연결 사이트 전체까지 점검: 점검 범위와 시간 예산이 확대되므로 사용자는 제한된 범위를 선택했다.
- 로그인된 콘텐츠와 사이트 변경 작업까지 포함: 사용자는 공개 페이지의 읽기 점검으로 한정했다.

## 결과

외부 iframe을 읽을 수 있어도 해당 외부 사이트의 링크를 자동 순회하지 않는다. 로그인하지 않아 접근할 수 없는 콘텐츠는 확인 불가이며 정상이라고 간주하지 않는다. 탐지 결과는 사이트 관리자 검토를 지원하고 자동 삭제를 수행하지 않는다.
