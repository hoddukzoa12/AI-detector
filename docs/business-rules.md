# 업무 규칙

## 목적과 대상

공공 웹사이트에 게시되거나 은닉된 불법광고를 찾아 사이트 관리자가 검토할 수 있게 한다. 도박·성인물 등의 광고 여부와 은닉 기법을 구분한다. CSS로 숨겨졌다는 사실만으로 불법광고라고 판단하거나, 정상 기사에서 도박·성인물 관련 단어가 나온다는 이유만으로 광고라고 판단하지 않는다.

사용자가 입력한 URL과 같은 호스트의 공개 하위 페이지, 게시글, 댓글, 포함된 iframe이 점검 대상이다. 다른 서브도메인을 별도 페이지로 순회하지 않고, 외부 호스트로 이동하는 페이지 링크·리다이렉트도 순회 대상에 추가하지 않는다. 페이지 안에 포함된 외부 iframe은 내용 점검 대상이 될 수 있으나, 외부 광고 링크를 따라 외부 사이트 전체를 탐색하지 않는다. 로그인하거나 폼을 제출하거나 게시물을 작성·수정·삭제하지 않는다.

## 원문과 탐지 단위

탐지는 정규화 전 원문, 페이지 URL, 요소 위치를 보존한 상태에서 수행한다. 문자 복원·정규화는 별도 분석 값에 적용하고, 결과의 근거 텍스트를 복원된 문자열로 대체하지 않는다. 입력 URL 하나에서 탐색한 모든 페이지의 결과를 하나의 실행으로 묶는다.

결과 한 건의 단위는 페이지 URL + 요소 위치 + 은닉 기법이다. 같은 요소에 두 기법이 적용되면 기법별로 두 건을 출력한다. 같은 요소 안에 동일 기법의 문자열이 여럿 있어도 한 건으로 집계한다. 동일 조합을 여러 번 찾았다고 중복 건수를 늘리지 않는다.

부모와 자식이 각각 직접 소유한 글자는 문구가 같아도 별도 원문이다. 부모에는 숨긴 글자, 자식에는 보이는 같은 글자가 있으면 숨긴 부모의 탐지를 버리지 않는다. 자식 글자를 합쳐 부른 집계 부모는 추가 탐지로 세지 않는다.

## 필수 은닉 유형

| 유형 | 판정해야 할 현상 | 주의할 반례 |
|---|---|---|
| 닮은꼴 글자 위장 | 비슷하게 보이는 문자·숫자를 섞어 광고 문구의 키워드 매칭을 피함 | 문자 혼용만으로 광고 여부를 확정하지 않는다 |
| 자모 분해 | 한글 음절을 자모 단위로 나누어 광고 문구를 은닉함 | 분해된 한글이라는 사실과 불법광고 문맥을 함께 판정한다 |
| 투명 텍스트 | 배경과 동일 색상, opacity 0, transparent 색상 등으로 광고 텍스트를 숨김 | 정상 접근성 보조 문구나 장식 요소를 광고로 집계하지 않는다 |
| 화면 밖 은닉 | 0~1px 글자, 화면 밖 위치, display none 등으로 광고를 감춤 | 일반 스크롤 아래에 있다는 사실만으로 화면 밖 은닉이라고 판정하지 않는다 |

부모 요소의 스타일과 프레임 문맥이 자식 텍스트의 은닉에 영향을 줄 수 있다. 현재 화면에 보이는 큰 요소만 수집하면 안 된다. 자모·닮은꼴 변형 복원은 분석 값에만 적용하며 정상 기사·공공 안내·교육·접근성 문맥을 광고 홍보와 구분한다. 광고 문맥은 CLEF만 판정한다. DOM에서 은닉 기법을 확인한 모든 직접 텍스트 후보를 분류하고 광고 키워드로 후보를 제외하거나 확정하지 않는다. 불확실하거나 분류에 실패한 후보는 별도 검토 목록에 남기고 확정 탐지로 넣지 않는다. 로컬 광고 판정이나 실패 시 대체 판정은 제공하지 않는다.

## 이미지 광고와 입력 귀속

CLEF 전송 동의와 키는 점검 시작에 필수다. 이미지 OCR은 기본 꺼짐이며 사용자가 PNG 전송을 선택한 실행에서만 확보·추출한다. 미선택 이미지를 점검 완료나 비광고로 표시하지 않는다.

일반·숨김 img와 CSS 배경·before/after URL 이미지를 점검한다. 움직이는 이미지는 첫 프레임만 분석하고 캔버스·영상·CSS 도형·나머지 프레임을 점검했다고 주장하지 않는다. 그림만 있는 광고는 글자 기반 분류로 놓칠 수 있다. OCR은 글자와 읽기 상태만 제공하고 확정 여부는 읽힌 글자의 CLEF 판정으로 정한다.

관련 링크는 소유 요소를 포함하는 가장 가까운 anchor에 한정한다. 부모 메뉴 전체 텍스트·형제 광고 링크를 MEMBER·MENU 같은 제목에 합치지 않는다. 특정 메뉴 문구를 제외 목록에 넣는 방식도 사용하지 않는다.

이미지 탐지 한 건은 페이지·프레임·소유 요소 단위다. 같은 소유자의 여러 이미지에서 읽힌 원문을 img·CSS 배경·before·after 순서와 레이어 순서로 연결하며 각 원문 범위를 보존한다. 다른 소유자에서 같은 PNG를 사용하면 OCR 추출만 재사용하고 링크·판정은 각 소유자별로 유지한다. 직접 DOM 원문과 OCR 글자는 같은 요소여도 합쳐 공식 결과로 만들지 않는다.

읽을 수 있는 원문만 CLEF에 보낸다. 부분 읽기·읽기 불가·API 오류·미처리는 검토와 미완료 범위에 남긴다. 글자 없음은 정상 추출 완료지만 검토이며 비광고 확정이 아니다. 읽기 불가를 임의 글자나 숫자 OCR 신뢰도로 채우지 않는다.

## 사용자가 확인할 결과

결과 화면은 URL, 은닉 유형, 원문 근거, 정확한 요소 위치를 확인할 수 있어야 한다. 사용자가 근거를 검토하고 관리 업무에 활용할 수 있게 하되, 탐지기가 사이트의 광고를 자동 삭제하거나 사이트 상태를 수정하지 않는다. 근거 파일의 해시는 저장 바이트의 무결성을 확인하는 값이며 법적 효력을 보장하는 인증으로 표현하지 않는다.

검출이 없어도 빈 결과를 출력한다. 접근 실패, 분석 실패, 중단된 실행을 '불법광고 없음'으로 표시하지 않는다. 실행 상태와 확인한 범위를 결과 화면에서 구분한다. 접근 실패·선택한 OCR 또는 필수 CLEF 분석 실패·중단 시에도 확인된 탐지는 저장하고 화면과 별도 실행 기록에 부분 완료·실패·중단 상태 및 미완료 범위를 남긴다. 평가용 JSON에 임의의 성공 상태나 은닉 유형을 추가하지 않는다. 미점검 URL·접근/프레임/AI/저장 오류와 검토 후보를 공식 확정 결과와 별도로 보존한다.

추가 탐지 유형을 구현하면 필수 네 유형과 별도로 관리한다. 추가 결과가 필수 유형의 개수나 적격평가 결과에 섞이지 않아야 한다.

## 기존 기능의 위치

사용자 프로필 우선순위, 자동 마스킹, 이름 감시, 차단 템플릿, 모바일 동등성은 기존 소비자 제품에 구현된 동작이다. 공모전용 도구의 새 업무 규칙으로 승계하지 않는다. 재사용 코드를 변경할 때 저장된 규칙·증거가 손실되지 않도록 하되, 이전 제품의 기능을 공모전의 제출 요건으로 추가하지 않는다.

## 판정과 종료

CLEF 확정은 최고 확률 선택지가 illegal_ad이고 해당 확률이 0.8 이상일 때다. confidence를 확률로 대신하지 않는다. uncertain 또는 임계값 미만은 검토, 충분히 확신한 일반 광고·비광고는 제외한다. 한 후보의 양성 조각이 확인되면 요소·기법별 확정은 유지하고 나머지 미완료·오류·불확실 조각은 검토에 남긴다. 모든 조각이 충분히 확신한 음성일 때만 검토 없이 제외한다. 일부 조각만 검사한 것을 후보 전체 음성으로 바꾸지 않는다.

동시에 활성 실행은 하나다. running→stopping→cancelled 또는 running→completed/partial/failed로 종료하며 터미널 상태·확정 결과는 이후 응답으로 바뀌지 않는다. 이미 종료한 실행을 다시 중단해도 동일 자료를 유지한다. 저장 실패는 failed, 저장 성공한 사용자 중단은 cancelled, 확인 페이지가 있지만 접근·선택 OCR·필수 CLEF·상한으로 미완료면 partial, 수집 페이지가 없거나 치명 오류이면 failed다. 불확실 검토 후보만 있는 정상 종료는 completed일 수 있다.

초기 범위는 500페이지·수집/분류 28분·1280×720이다. 제한에 도달하면 새 작업을 예약하지 않고 대기 URL과 이유를 남긴다. 종료·저장을 포함한 30분 조건의 실제 대상 PC 검증은 별도다. 프레임 탐지는 top-page URL 문맥을 유지하고 같은 외부 프레임을 다른 상위 페이지에서 읽은 자료를 합치지 않는다.
